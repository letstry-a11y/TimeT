  学习路线（建议顺序）

  第一阶段：基础（2-4周）

  1. HTML/CSS 基础
  - 学习 HTML 标签、CSS 样式
  - 推荐：MDN Web Docs（免费）

  2. JavaScript 基础
  - 变量、函数、数组、对象
  - 异步编程（Promise、async/await）
  - 推荐：JavaScript.info（免费）

  3. Python 基础
  - 语法、数据结构、函数
  - 推荐：Python 官方教程

  ---
  第二阶段：框架入门（4-6周）

  4. React 基础
  - 组件、Props、State
  - Hooks（useState, useEffect）
  - 推荐：React 官方文档

  5. TypeScript 基础
  - 类型注解、接口、泛型
  - 推荐：TypeScript 官方手册

  6. FastAPI 基础
  - 路由、请求/响应
  - 依赖注入
  - 推荐：FastAPI 官方文档（非常友好）

  ---
  第三阶段：进阶（4-6周）

  7. Next.js
  - 页面路由、API Routes
  - 服务端渲染
  - 推荐：Next.js 官方教程

  8. 数据库 & SQLAlchemy
  - SQL 基础
  - ORM 概念
  - 推荐：SQLAlchemy 教程

  9. Tailwind CSS
  - 实用类优先的 CSS
  - 推荐：Tailwind 官方文档

  ---
  实践建议

  边学边做

  1. 先运行本项目，理解它做什么
  2. 尝试修改小功能（如改文字、改颜色）
  3. 阅读代码，理解数据流向
  4. 尝试添加简单功能

  项目文件结构理解

  TimeFeatureAdd/
  ├── backend/                 # 后端代码
  │   ├── app/
  │   │   ├── api/            # API 路由
  │   │   ├── crud/           # 数据库操作
  │   │   ├── models/         # 数据模型
  │   │   └── schemas/        # 数据验证
  │   └── run.py              # 启动入口
  │
  ├── frontend/               # 前端代码
  │   ├── src/
  │   │   ├── app/           # 页面组件
  │   │   ├── components/    # 通用组件
  │   │   ├── hooks/         # 自定义 Hooks
  │   │   ├── lib/           # 工具函数和 API
  │   │   └── i18n/          # 国际化
  │   └── package.json       # 依赖配置

  推荐学习顺序（针对本项目）

  1. 先看 frontend/src/app/(dashboard)/ 下的页面
  2. 理解 hooks/ 如何获取数据
  3. 看 backend/app/api/ 理解 API
  4. 看 backend/app/crud/ 理解数据库操作
