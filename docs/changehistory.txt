  - Added TimeLogPlanned schema for creating planned tasks

  - Added create_planned() function for creating planned entries
  - Added update_status() function for updating task status

  - Added POST /timelogs/planned endpoint

  - Created migration to add status column to time_logs table

  To Apply Database Migration

  Run the following command in the backend directory:
  cd backend
  alembic upgrade head

  Or for SQLite, you may need to manually add the column:
  ALTER TABLE time_logs ADD COLUMN status VARCHAR(20);

  新功能说明

  在"时间追踪"页面，你现在可以：

  1. 创建计划 - 点击右上角"创建计划"按钮，预先安排某个时间段的工作
  2. 天/周视图切换 - 使用右侧的"按天"/"按周"按钮切换视图
  3. 日期导航 - 使用左右箭头浏览不同日期，点击"今天"快速回到当天
  4. 标记计划状态 - 对于待完成的计划任务，可以点击 ✓ 标记完成或 ✗ 标记未完成
  5. 按天分组显示 - 记录按日期分组，每天显示总计时长
