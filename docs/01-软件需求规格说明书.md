# TimeTracker 软件需求规格说明书

**文档版本**: 1.0
**创建日期**: 2026-01-23
**项目名称**: TimeTracker - 目标导向时间追踪系统

---

## 1. 引言

### 1.1 编写目的

本文档详细描述 TimeTracker 时间追踪系统的功能需求和非功能需求，为系统设计、开发和测试提供依据。

### 1.2 项目背景

TimeTracker 是一个目标导向的时间追踪系统，旨在帮助用户：
- 设定长期愿景和年度/季度目标
- 追踪时间投入与目标的关联
- 分析时间分配是否与愿景对齐
- 通过数据驱动的方式提升时间利用效率

### 1.3 术语定义

| 术语 | 定义 |
|-----|------|
| 愿景 (Vision) | 用户的长期目标或人生方向，如"成为技术专家" |
| 年度目标 (Yearly Goal) | 围绕愿景制定的年度计划 |
| 季度目标 (Quarterly Goal) | 年度目标分解的季度执行计划 |
| 时间日志 (TimeLog) | 单次时间记录，包含开始/结束时间和关联目标 |
| 打卡 (Clock In) | 实时计时方式 |
| 补录 (Manual Entry) | 手动记录历史时间 |
| 计划任务 (Planned) | 预先规划的时间块 |

## 2. 系统概述

### 2.1 系统目标

1. **目标管理**: 建立愿景→年度目标→季度目标的三层管理体系
2. **时间追踪**: 支持实时打卡、手动补录、计划任务三种记录方式
3. **数据分析**: 生成愿景对齐、目标进度、周报等多维度报告
4. **用户体验**: 提供简洁直观的界面，支持中英文双语

### 2.2 用户角色

| 角色 | 描述 | 权限 |
|-----|------|------|
| 普通用户 | 系统主要使用者 | 管理自己的愿景、目标、时间记录 |
| 管理员 | 系统维护人员 | 用户管理（预留功能） |

## 3. 功能需求

### 3.1 用户认证模块 (FR-AUTH)

#### FR-AUTH-001 用户注册
- **优先级**: 高
- **描述**: 新用户可以创建账户
- **输入**: 邮箱、用户名、密码
- **处理**:
  - 验证邮箱格式
  - 验证用户名唯一性（≥3字符）
  - 验证密码强度（≥8字符）
  - 密码加密存储
- **输出**: 注册成功/失败消息

#### FR-AUTH-002 用户登录
- **优先级**: 高
- **描述**: 已注册用户可以登录系统
- **输入**: 邮箱/用户名、密码
- **处理**:
  - 验证用户存在
  - 验证密码正确
  - 生成 JWT Token
- **输出**: 访问令牌 + 刷新令牌

#### FR-AUTH-003 令牌刷新
- **优先级**: 高
- **描述**: 使用刷新令牌获取新的访问令牌
- **输入**: 刷新令牌
- **输出**: 新的访问令牌 + 刷新令牌

#### FR-AUTH-004 用户登出
- **优先级**: 中
- **描述**: 用户退出登录
- **处理**: 清除本地令牌

### 3.2 愿景管理模块 (FR-VISION)

#### FR-VISION-001 创建愿景
- **优先级**: 高
- **描述**: 用户可以创建新的愿景
- **输入**:
  - 标题（必填，≤200字符）
  - 描述（可选）
  - 目标年份（可选）
  - 颜色（可选，16进制颜色值）
- **输出**: 创建的愿景对象

#### FR-VISION-002 查看愿景列表
- **优先级**: 高
- **描述**: 用户可以查看自己的所有愿景
- **输出**: 按 sort_order 排序的愿景列表

#### FR-VISION-003 编辑愿景
- **优先级**: 高
- **描述**: 用户可以修改愿景信息
- **可修改字段**: 标题、描述、目标年份、颜色

#### FR-VISION-004 删除愿景
- **优先级**: 中
- **描述**: 用户可以删除愿景
- **约束**: 删除愿景将级联删除关联的年度目标和季度目标
- **确认**: 需要用户二次确认

#### FR-VISION-005 调整愿景排序
- **优先级**: 中
- **描述**: 用户可以调整愿景的显示顺序
- **操作**: 上移/下移按钮
- **影响**: 更新 sort_order 字段

#### FR-VISION-006 查看愿景关联目标
- **优先级**: 中
- **描述**: 展开查看愿景下的年度目标和季度目标
- **显示**: 目标名称、进度、状态

---

### 3.3 目标管理模块 (FR-GOAL)

#### FR-GOAL-001 创建年度目标
- **优先级**: 高
- **描述**: 用户可以创建关联到愿景的年度目标
- **输入**:
  - 标题（必填）
  - 描述（可选）
  - 关联愿景（必填）
  - 年份（必填）
  - 目标时长（可选，小时）
- **约束**: 必须关联到一个愿景

#### FR-GOAL-002 创建季度目标
- **优先级**: 高
- **描述**: 用户可以创建关联到年度目标的季度目标
- **输入**:
  - 标题（必填）
  - 描述（可选）
  - 关联年度目标（必填）
  - 季度（必填，1-4）
  - 目标时长（可选，小时）
- **约束**: 必须关联到一个年度目标

#### FR-GOAL-003 查看目标列表
- **优先级**: 高
- **描述**: 用户可以查看目标列表
- **筛选条件**:
  - 年份
  - 季度（全部/Q1/Q2/Q3/Q4）
- **显示模式**:
  - 全部：层级视图（年度目标→季度目标）
  - 指定季度：扁平列表

#### FR-GOAL-004 编辑目标
- **优先级**: 高
- **描述**: 用户可以修改目标信息
- **可修改字段**: 标题、描述、目标时长、关联愿景（仅年度目标）

#### FR-GOAL-005 删除目标
- **优先级**: 中
- **描述**: 用户可以删除目标
- **约束**: 删除年度目标将级联删除其下的季度目标
- **确认**: 需要用户二次确认

#### FR-GOAL-006 更新目标状态
- **优先级**: 高
- **描述**: 用户可以更新目标的执行状态
- **状态选项**:
  - 未开始 (not_started)
  - 进行中 (in_progress)
  - 已完成 (completed)
  - 已暂停 (paused)
  - 已取消 (cancelled)

#### FR-GOAL-007 调整目标排序
- **优先级**: 中
- **描述**: 用户可以调整目标的显示顺序
- **规则**:
  - 年度目标：在同一年份内排序
  - 季度目标：在同一年度目标下排序

#### FR-GOAL-008 自动进度计算
- **优先级**: 高
- **描述**: 系统自动计算目标进度
- **计算规则**:
  - 进度 = (累计时长 / 目标时长) × 100%
  - 季度目标累计时长向上汇总到年度目标

### 3.4 时间追踪模块 (FR-TIMELOG)

#### FR-TIMELOG-001 开始计时
- **优先级**: 高
- **描述**: 用户可以开始实时计时
- **输入**:
  - 关联目标（必填，仅限季度目标）
  - 备注（可选）
- **约束**: 同一时间只能有一个运行中的计时
- **输出**: 创建计时记录，显示运行状态

#### FR-TIMELOG-002 停止计时
- **优先级**: 高
- **描述**: 用户可以停止当前计时
- **处理**:
  - 记录结束时间
  - 计算持续时长
  - 更新目标累计时长

#### FR-TIMELOG-003 手动补录
- **优先级**: 高
- **描述**: 用户可以手动添加历史时间记录
- **输入**:
  - 关联目标（必填）
  - 开始时间（必填）
  - 结束时间（必填）
  - 备注（可选）
- **约束**: 结束时间必须大于开始时间

#### FR-TIMELOG-004 创建计划任务
- **优先级**: 中
- **描述**: 用户可以创建计划中的时间块
- **输入**:
  - 关联目标（必填）
  - 计划开始时间（必填）
  - 计划结束时间（必填）
  - 备注（可选）
- **初始状态**: 待完成 (pending)

#### FR-TIMELOG-005 更新计划任务状态
- **优先级**: 中
- **描述**: 用户可以标记计划任务的完成状态
- **状态选项**:
  - 待完成 (pending)
  - 已完成 (completed)
  - 未完成 (not_completed)
- **规则**: 仅 completed 状态计入累计时长

#### FR-TIMELOG-006 查看时间日志
- **优先级**: 高
- **描述**: 用户可以查看时间记录
- **视图模式**:
  - 日视图：显示单日记录
  - 周视图：显示一周记录
- **导航**: 支持前后日期切换、今天快捷按钮

#### FR-TIMELOG-007 编辑时间日志
- **优先级**: 中
- **描述**: 用户可以修改已有记录
- **可修改字段**: 开始时间、结束时间、备注

#### FR-TIMELOG-008 删除时间日志
- **优先级**: 中
- **描述**: 用户可以删除时间记录
- **确认**: 需要用户二次确认

---

### 3.5 报表分析模块 (FR-REPORT)

#### FR-REPORT-001 仪表盘概览
- **优先级**: 高
- **描述**: 显示用户的整体概况
- **内容**:
  - 愿景数量
  - 本季度目标数量
  - 本周投入时长
  - 平均完成进度
  - 当前运行中的计时
  - 本季度目标列表（前5个）
  - 周时间分布图
  - 愿景概览
  - 本周热门目标

#### FR-REPORT-002 愿景对齐报告
- **优先级**: 中
- **描述**: 分析时间在各愿景间的分配
- **内容**:
  - 每个愿景的投入时长
  - 占总时长的百分比
  - 进度条可视化
- **筛选**: 支持时间范围筛选

#### FR-REPORT-003 目标进度报告
- **优先级**: 中
- **描述**: 显示目标的完成进度
- **内容**:
  - 目标名称和类型
  - 状态
  - 进度百分比
  - 累计时长 vs 目标时长
- **筛选**: 年份、季度

#### FR-REPORT-004 周报告
- **优先级**: 中
- **描述**: 显示一周的时间投入情况
- **内容**:
  - 总投入时长
  - 每日投入分布
  - 本周 TOP 5 目标

## 5. 数据需求

### 5.1 数据实体

| 实体 | 描述 | 主要字段 |
|-----|------|---------|
| User | 用户 | id, email, username, password |
| Vision | 愿景 | id, title, description, color, target_year |
| Goal | 目标 | id, title, goal_type, year, quarter, target_hours |
| TimeLog | 时间日志 | id, start_time, end_time, log_type, status |

### 5.2 数据关系

```
User (1) ──────────────────┬──── (N) Vision
                           │
                           ├──── (N) Goal
                           │        │
                           │        └──── (parent-child)
                           │
                           └──── (N) TimeLog

Vision (1) ──── (N) Goal (yearly only)

Goal (1) ──────┬──── (N) Goal (quarterly)
               │
               └──── (N) TimeLog (quarterly only)
```

### 5.3 数据量估算

| 数据 | 预估量/用户/年 |
|-----|---------------|
| 愿景 | 3-10 个 |
| 年度目标 | 5-20 个 |
| 季度目标 | 20-80 个 |
| 时间日志 | 500-2000 条 |

## 7. 约束和假设

### 7.1 技术约束

- 前端必须支持主流浏览器（Chrome、Firefox、Safari、Edge）
- 后端使用 Python 3.10+
- 数据库支持 PostgreSQL 或 SQLite

### 7.2 业务约束

- 时间只能记录到季度目标（不能记录到年度目标或愿景）
- 每个用户同时只能有一个运行中的计时
- 计划任务只有标记为"已完成"才计入统计

### 7.3 假设

- 用户具有基本的计算机操作能力
- 网络连接稳定
- 服务器时区统一为 UTC
