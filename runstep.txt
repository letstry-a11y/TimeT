
启动后端
这是一个 FastAPI 后端服务的启动脚本，使用 uvicorn 在 8000 端口运行。让我启动它。

● Bash(cd "D:\ai demo\TimeTrackVersion\backend" && python run.py)
  ⎿  Running in the background (↓ to manage)

● 找到了！这个应用的 API 路由有前缀。以下是可用的访问地址：
  ┌────────────────────────────────────┬──────────────────────┐
  │                地址                │         说明         │
  ├────────────────────────────────────┼──────────────────────┤
  │ http://localhost:8000/health       │ 健康检查             │
  ├────────────────────────────────────┼──────────────────────┤
  │ http://localhost:8000/api/v1/docs  │ Swagger API 文档界面 │
  ├────────────────────────────────────┼──────────────────────┤
  │ http://localhost:8000/api/v1/redoc │ ReDoc API 文
