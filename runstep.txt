# TimeTracker 启动步骤

## 环境要求
- Python 3.10+
- Node.js 18+
- npm

## 1. 启动后端服务

```bash
cd backend
pip install -r requirements.txt    # 首次运行需要安装依赖
python run.py
```

后端服务地址:
- API 服务: http://localhost:8000
- 健康检查: http://localhost:8000/health
- API 文档: http://localhost:8000/api/v1/docs
- ReDoc 文档: http://localhost:8000/api/v1/redoc

## 2. 启动前端服务

```bash
cd frontend
npm install    # 首次运行需要安装依赖
npm run dev
```

前端服务地址:
- 应用界面: http://localhost:3000

## 3. 访问应用

打开浏览器访问 http://localhost:3000

首次使用需要注册账号:
1. 点击 "Register" 注册新账号
2. 填写邮箱、用户名、密码
3. 注册成功后登录即可使用

|----------|-------------------------|----------------|
